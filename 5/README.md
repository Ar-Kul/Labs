# Лабораторная работа №5: Регулярные выражения

## Задание 1: NumberFinder.java
Поиск всех чисел в тексте. Регулярное выражение: -?\d+(?:[.,]\d+)? (целые, дробные, отрицательные).

## Задание 2: PasswordValidator.java
Проверка пароля: только латиница и цифры, длина 8-16, хотя бы одна заглавная и одна цифра.
Регулярное выражение: ^(?=.*[A-Z])(?=.*\d)[A-Za-z\d]{8,16}$

## Задание 3: LowercaseUppercaseFinder.java
Поиск сочетаний "строчная буква + заглавная буква". Замена на $1!$2! (вставка ! между буквами и после заглавной).
Регулярное выражение: ([a-zа-яё])([A-ZА-ЯЁ])

## Задание 4: IPAddressValidator.java
Проверка IP-адреса: 4 числа от 0 до 255, без ведущих нулей. Сначала проверка формата через регулярку, затем разбивка и проверка диапазона.

## Задание 5: WordFinderByLetter.java
Поиск слов, начинающихся с заданной буквы. Регулярное выражение: \b\p{L}+\b (любые буквы любого алфавита). Регистронезависимое сравнение.

Запуск: каждый класс запускается отдельно
